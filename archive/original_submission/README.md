\# Customer Churn Prediction Using Machine Learning



\## 1. Project Overview



Customer churn refers to customers discontinuing their relationship with a company or service provider.



This project uses machine learning techniques to predict whether a customer is likely to churn based on customer demographic, service, contract, and billing information.



A Streamlit web application was developed to allow users to enter customer information and receive a churn prediction, churn probability, and risk level.



\## 2. Objectives



\- Predict whether a customer is likely to churn.

\- Compare different machine learning algorithms.

\- Select a suitable final model based on evaluation metrics.

\- Identify important features affecting churn prediction.

\- Deploy the trained model using Streamlit.



\## 3. Machine Learning Models



The following models were evaluated:



\- Logistic Regression

\- Random Forest

\- XGBoost



\## 4. Final Model



XGBoost was selected as the final model based on the obtained evaluation results.



\## 5. Application



The trained model is deployed using Streamlit.



The application accepts customer information and displays:



\- Churn prediction

\- Churn probability

\- Risk level
